# PAI2D-2026



## Titre du projet
PAI2D : Assistance à l'usage des logiciels complexes avec les VLM. 

## Description
Ce projet à pour but de développer une extension pour le logiciel d'édition d'image GIMP, 
aussi appelé plugin, qui aidera l'utilisateur à découvrir des nouvelles commandes qui lui seront utiles. 

Ceci se fera par l'intérim d'un Vision Language Model (VLM).
